# TaskFlow

A modern full stack task management application built using React, Node.js, Express, MongoDB, and JWT Authentication.

---

## Features

- User Authentication
- JWT Authorization
- Add / Edit / Delete Tasks
- Protected Routes
- Dark Mode
- Responsive UI
- Task Filtering

---

## Tech Stack

### Frontend
- React
- Tailwind CSS
- Axios
- React Router DOM

### Backend
- Node.js
- Express.js
- MongoDB
- JWT
- bcryptjs

---

## Setup Instructions

### Clone Repository

```bash
git clone https://github.com/sanyaarora2/taskflow.git
```

### Frontend Setup

```bash
cd FRONTEND
npm install
npm run dev
```

### Backend Setup

```bash
cd BACKEND
npm install
npm start
```
